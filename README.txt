Excel転記アプリ（Streamlit）

【起動手順】

1. コマンドプロンプトを開く
2. このフォルダに移動
   cd C:\Users\a.hidaka\projects\excel_tenki_app

3. 仮想環境を有効化
   .venv\Scripts\activate

4. 必要なライブラリをインストール
   pip install -r requirements.txt

5. アプリを起動
   streamlit run main.py
   ※python -m streamlit run main.py


※ Excel がインストールされているPCで実行してください
※ 同時に複数人で実行しないでください（Excel COM使用）
